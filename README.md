DocuMind is a web application that lets you upload your own documents and ask questions about them.
Think of it as a personal assistant that reads your PDF documents and helps you find the information you need without manually reading every page.

Technology What it does
Python + FastAPI Handles uploads and processes documents on the backend.
PyMuPDF Extracts text from PDF files.
Text splitting Breaks large documents into smaller chunks.
Machine learning Will help rank document sections by relevance.
React Will provide the website interface where users upload files and ask questions.
